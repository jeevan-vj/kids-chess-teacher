# Kids Chess Teacher

A simple, interactive, kid-friendly web app to learn chess board coordinates (A1–H8) and how the pieces move.

## Features
- Click any square to see and hear its name
- Place White or Black pieces and see possible moves highlighted
- Voice instructions (uses browser speech)
- Mobile-friendly

## Live site
Once GitHub Pages is enabled (Settings → Pages → Deploy from branch: main / root), it will be available at:

## How to use
Open the site, click squares, choose a piece, and explore!
